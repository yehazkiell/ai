# AI itu ⚡️

**AI itu** is an advanced AI Super Agent platform that combines the intelligence of world-class LLMs with a powerful suite of automation tools. Inspired by a fusion of ChatGPT, Grok, Claude, Gemini, Jules, and specialized agents like Manus and OpenClaw, **AI itu** is designed to be your ultimate companion for development, creativity, and daily tasks.

## 🚀 Features

- **Multi-Brain Sync**: Seamlessly switch between **OpenAI (GPT-4o)**, **Anthropic (Claude 3.5)**, **Google (Gemini 1.5 Pro)**, and **xAI (Grok)**.
- **Super Agent Capabilities**:
  - 🛠 **Dev Ops**: Automated GitHub repository management, npm package analysis, and Hugging Face model searching.
  - 🎨 **Creative Suite**: Generates automation scripts for **Blender (Python)**, **Roblox Studio (Luau)**, and editing advice for **CapCut**.
  - 🔍 **Neural Search**: Real-time web browsing and information retrieval.
- **Dynamic Visuals**: Automatically renders **Mermaid Diagrams** (flowcharts, sequence diagrams, etc.) directly in the chat.
- **Social Integration**: Built-in **WhatsApp** connection to send messages and automate communications.
- **Sleek Browser UI**: A premium, dark-themed dashboard built for speed and ease of use.
- **Client-Side Security**: Your API keys are stored safely in your browser's local storage.

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **AI Core**: [Vercel AI SDK](https://sdk.vercel.ai/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Diagrams**: [Mermaid.js](https://mermaid.js.org/)
- **State Management**: React Hooks & Local Storage

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/ai-itu.git
   cd ai-itu
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables** (Optional - you can also input keys in the UI):
   Create a `.env.local` file:
   ```env
   OPENAI_API_KEY=your_key
   ANTHROPIC_API_KEY=your_key
   GOOGLE_GENERATIVE_AI_API_KEY=your_key
   XAI_API_KEY=your_key
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Open the browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

## 🧩 How to Use

1. **Configure**: Go to the **Settings** tab and enter your API keys for your preferred providers.
2. **Chat**: Use the **Neural Chat** to ask questions, write code, or generate diagrams.
3. **Automate**: Try prompts like:
   - *"Draw a sequence diagram for a login system."*
   - *"Create a GitHub repo named 'my-nextjs-app'."*
   - *"Write a Blender script to create a forest of cubes."*
   - *"Search Hugging Face for the latest Llama models."*
4. **Connect**: Link your phone number in the **WhatsApp** tab to enable messaging tools.
